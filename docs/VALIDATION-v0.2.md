# ReadDock 0.2 验证说明

## 数学截图的真实验证

已获得用户明确授权，使用词舟中保存的 DeepSeek Key，将其提供的数学截图发送到 DeepSeek 官方 API 实测一次。Key 未显示、导出或写入报告。

返回结果正确包含：

- `q_1, q_2, \ldots, q_k`
- `p_1, p_2, \ldots, p_k`
- `2k`

原文与中文译文均保留上述变量及下标，模型未报告不确定字符。本次输入 488、输出 180 tokens。这是单张截图的实测结果，不是所有数学文献的准确率评估。

旧版本地中文 OCR 对同一图片的误读已复现；放大和对比度增强仍不足以可靠还原全部变量，因此数学文献默认使用视觉识别，可在设置中切回本地 OCR。

## 自动验证

已通过：

- 旧单个笔记路径转为单词本列表；默认项和当前项分离。
- 多单词本分别写入、分别去重；重复路径拒绝保存。
- 默认模板精简；旧原版模板备份迁移；自定义模板保留。
- Markdown 内容转义和内联 LaTeX 保留。
- 视觉请求直接发送图片并保留原始细节，JSON 解析及空识别结果拒绝。
- 新请求不携带此前的翻译或图片历史。
- 弹窗位于选区下方，空间不足翻到上方，并处理屏幕边缘和负坐标副屏。
- 数学下标及希腊字母的简单显示；复杂公式保留 LaTeX。
- 深色模式、背景亮度、强调色、ICO Logo 读取及原文件无锁占用。
- UTF-8 原字节保留、追加、文件锁、备份、撤销与外部编辑冲突。
- 真实 Windows OCR 的普通英文识别。

## 界面检查

已实际打开检查：深色主界面、单词本下拉入口、视觉设置、多个 Markdown 路径与默认项、Logo/颜色/亮度设置及轻量示例弹窗。当前电脑为 150% 缩放。
