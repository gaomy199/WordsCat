## 构建及本地回归

- `build.ps1` 成功，无编译警告，产物 `publish/WordsCat.exe`，版本 0.3.2。
- `verify.ps1 -IncludeUi` 全部通过。最终报告：`.test-results/1552374d5c2a4ba0a96d49cecc7b9705/`。
- 报告包括 `test-results.txt`、`ui/ui-test-results.txt`，以及隔离界面的 `ui/layout-main.json`。

新增检查：

1. 英文句子和单词自动请求中文；中文句子和词语自动请求英文。混排专业术语、数学公式、LaTeX 命令和单字母变量不会直接决定正文语言。
2. 旧配置中的手动方向迁移为 `auto`，自定义翻译要求保留；明确的自动目标语言优先于冲突的翻译要求。界面语言独立于翻译方向。
3. 模拟 HTTP 请求中连续发送英文、中文，实际序列化的 system 消息分别指定中文、英文，第二个请求不含第一个选区。视觉提示同时覆盖中文/英文的自动判断。
4. 实际 STA 窗口中取消手动方向选择，输入中文后标题和方向提示自动更新；交换后按新原文重新识别，清除旧译文和追问。
5. 左侧仅有当前语言品牌；英文保存/预览后仅显示 WordsCat，不再显示中文副标题。新操作图标可用。
6. 默认嵌入 ICO 可创建窗口/托盘图标及高分辨率 Logo；自定义 ICO 可覆盖，恢复默认后重新使用内置资源。EXE 使用同一 ICO 编译。
7. 原有模板、Markdown、历史、布局边界、语言即时预览、数学字体、弹窗、任务栏和连续展开回归继续通过。

第一次 UI 回归发现原文编辑页隐藏且未创建句柄时，RichTextBox 不发出文本变化通知，导致自动标题仍停留在空状态；已在主窗口首次显示时创建原生编辑句柄，修正后重跑完整验证通过。

## Computer Use

用 computer-use 技能在正常桌面打开 `--offline-preview --data-dir <隔离目录>`，不读取用户运行配置或真实凭据：

- 查看粘贴、打开单词本、退出按钮的图标；查看单一语言名称及主窗口/设置窗口的新默认图标。
- 实际进入原文编辑页，把合成英文示例改成含英文术语与公式的中文句子，标题立即变为中文原文/英文译文，方向提示变为自动中文→英文；没有请求 API。
- 打开并取消设置后检查按钮，不再残留鼠标点击造成的强调外框。实际按 Tab 后「退出」按钮出现键盘焦点提示，再用鼠标点击空白区域后外框消失，确认两种输入方式区分正常。
- 分别查看中文浅色、英文深色设置页签，图标和文字按整体居中、固定 8 逻辑像素间距，「外观」等短标题前不再留大块空白，英文页签没有裁切。英文主窗口仅显示 WordsCat。

## 边界

本轮没有读取真实 Key、请求模型服务、上传用户文献或改动 E 盘用户正在运行的旧版程序及其 Data。自动方向针对中英文，纯数学输入按英→中处理；中英混排依据正文汉字与英文词数判断，极端均衡或缺少自然语言的内容仍可能有歧义。视觉识别及真实翻译质量没有新增联网实测证据。
