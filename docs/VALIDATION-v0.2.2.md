## 设计与边界

字体加载问题通过固定的同源 `reader.html`、JS、CSS、字体解决；没有更换数学表达式语义或将专业数学字形强行替换成普通正文字体。参考：[KaTeX 字体说明](https://katex.org/docs/font)、[微软本地资源映射](https://learn.microsoft.com/en-us/dotnet/api/microsoft.web.webview2.core.corewebview2.setvirtualhostnametofoldermapping)。

历史以当前 Windows 用户 DPAPI 加密，本地原子替换；短暂文件占用有有限重试，失败保留旧历史。没有历史备份。不可恢复指软件没有撤销入口，不等于存储介质取证擦除。

浏览器可能在主进程退出后才释放缓存锁，因此程序在必要时启动无窗口、短生命周期的同程序清理副本，只等待退出并删除本次命名目录；无常驻任务。强制结束遗留在下次启动清理。笔记备份、配置及私有测试样本不属于缓存，不删除。
