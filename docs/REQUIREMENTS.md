# 已确认需求

## 产品名称与语言

1. 产品英文名 WordsCat，中文名单词猫；保留旧设置、凭据、笔记、自定义模板与历史兼容。
2. 「设置 → 外观」可选择中文或英文界面，选择即即时预览主窗口及设置页；保存后持久保留，取消恢复原语言，重启保留已保存项。界面语言独立于翻译方向，不改写用户数据。
3. 中英互译：主界面左栏为原文、右栏为译文，自动识别正文语言；英文→中文、中文→英文，无需手动选择。划词、粘贴、编辑、截图均使用自动方向。当前不加入其他语言。
4. 「交换」把首次译文放入原文栏，重新自动识别语言，并清除旧译文和当前追问上下文；用户编辑已翻译原文后也清除旧译文与追问，再点击翻译。
5. 新历史附带方向，打开时恢复；旧历史默认为英文→中文。追问用当前界面语言回答。
6. 保存目标、置顶、阅读提示字号与单词本选择一致；保存目标垂直居中对齐。追问仅保留输入提示「输入语法、句意或追问当前选区其他问题」，输入框与按钮等高，保留单独的运行状态行。

## 阅读体验

1. Windows 11；常用阅读器为 Zotero、WPS。
2. 正常阅读英文文献，按需翻译选中区域，不要求整篇翻译。
3. 可选中文字时划词翻译；扫描 PDF 和图片可以截图识别。
4. 截图结果先在选区附近显示简洁弹窗，用户点击按钮才打开主界面。
   小窗与主界面共用公式阅读渲染；原「复制译文」按钮改为「显示原文」，点击后显示当前识别原文并可切回译文，内容可选中复制。保留原有面板外观和操作布局。
   小窗原文或译文中的选词应直接带入收藏编辑窗口，沿用本次原文作为补全语境。收藏窗口不得被置顶小窗遮挡；编辑期间暂时隐藏小窗，保存或取消后恢复，主窗口不自动打开。
5. 悬浮入口可拖动，提供翻译、收藏、手动修改和设置入口。
   悬停展开菜单，鼠标离开浮标和菜单后自动收起；移入菜单时保持展开。单击浮标切换展开/收起，不因同一次点击重新弹出；拖动后不展开菜单。
6. 主界面原文及译文渲染数学公式，保留段落、独立公式和编号；原文可编辑，并可查看本次原始截图核对精确排版。
7. 打开主界面即关闭结果小窗；连续截图/取词时无需先关闭上一次主界面。
8. 划词支持普通浏览器网页中的可复制文字。
9. 轻量弹窗按翻译行数自适应高度；达到原有高度上限后纵向滚动。
10. 英文正文使用 Times New Roman，数学公式正常加载专业数学字体，避免字体回退和过大段间空白。
11. 最小化保留 Windows 任务栏入口及当前内容；点 × 才隐藏到托盘，程序不退出。

## 本地历史与临时数据

1. 主界面左侧显示最近 N 次已完成翻译，默认 N=100；设置可调整，N=0 关闭并清空。
2. 历史只存原文/译文；截图、未完成输入、追问不写入历史。当前临时内容在新选区、清空或关闭时释放。
3. 缩小 N 时提示将永久删除的最早记录数量，明确软件内不可恢复，确认后才删除；取消保留现状。
4. 自动淘汰超出上限的最早记录，清理 OCR 与渲染器临时缓存；已收藏单词、Markdown 和配置保持兼容。
5. 左侧品牌与历史栏可收起/展开；收起时保留窄栏展开按钮，释放阅读空间，记住折叠状态，不改变当前原文、译文或历史数据。

## 模型与会话

1. 优先 DeepSeek API，用户在工具内配置 Key。
   模型请求通过可替换的 OpenAI 兼容文本/图片能力接口；原默认地址、模型及 ReadDock 凭据标识不变。默认总超时 100 秒、重试 0。Windows 本地 OCR 路径不变。
   设置提供 DeepSeek/自定义 OpenAI 兼容预设、HTTPS Base URL、模型名和掩码 Key 输入；不回显已保存 Key，留空保留、取消丢弃，仅写入 Windows 凭据管理器。测试连接只发最小文字请求，按未配置、401、402/429、网络/超时及格式异常提供双语结果。首次未配置时显示可关闭、可进入设置的非模态引导，文本视图继续可用。
2. 数学文献要考虑斜体拉丁字母 q/p、希腊字母和上下标。用户原图中的 q/p 是数学斜体拉丁字母。
3. 视觉模式发送框选图片；保留只在本地识别图片的 OCR 选项。
4. 默认调用不在聊天客户端创建新会话；每次翻译独立。追问限当前选区。
5. 千问、harness、Codex 插件可作为后续讨论方向，目前未要求优先实现。

## 生词与 Obsidian

1. 选择性收藏单词或词组，收藏前可以手动修改。
2. JSON 定义字段与 Markdown 模板，程序按模板写入用户指定的 Markdown 文件。
3. 支持多个领域单词本，例如 mathematics.md、vla.md；设置默认项。
4. 主界面可以切换目标，收藏窗口也可以选择；没有另选时使用默认/当前项。
5. 默认保留单词、原形、词性、语境释义、原句、原句译文。
6. 默认不放来源、页码、我的笔记、收藏日期。用户以后仍可自定义模板。
7. 保留已有笔记内容；按单词本去重，支持重复语境确认、备份与撤销。

## 外观

主界面名称在最左侧栏顶部，中文界面仅显示「单词猫」，英文仅显示「WordsCat」，不显示第二行重复名称；历史位于其下，标题在当前 DPI 下完整显示。左侧不再显示历史保留说明。按钮、阅读区、历史区和设置页采用柔和圆角，交换等简短操作可使用圆形图标按钮；重要操作及设置导航增加图标，选中导航使用主题色。设置导航中的图标与文字按整体排列，间距固定为 8 逻辑像素，避免短标题前产生过大留白。

设置中的下拉、单行及多行输入、历史条数均有清晰细边框；语言、主题等短选项采用紧凑宽度，文字与下拉箭头处于同一框内。

默认图标使用用户提供的 4.ico，项目内为 assets/wordscat.ico；用于 EXE、悬浮、托盘及窗口。用户可替换 Logo，修改主题色、深浅模式和背景亮度；已有自定义 Logo 优先保留。

主界面粘贴、打开单词本、退出等操作均带图标。鼠标点击结束或关闭设置后不残留强调外框；键盘 Tab/方向键导航时保留清晰的焦点提示。

外观切换立即预览，保存保留、取消恢复；禁用按钮文字也应适配当前主题。自定义浮标 Logo 不被强调色染色。
