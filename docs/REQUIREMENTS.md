# 已确认需求

## 产品名称与语言

1. 产品英文名 WordsCat，中文名单词猫；保留旧设置、凭据、笔记、自定义模板与历史兼容。
2. 「设置 → 外观」可选择中文或英文界面，选择即即时预览主窗口及设置页；保存后持久保留，取消恢复原语言，重启保留已保存项。界面语言独立于翻译方向，不改写用户数据。
3. 中英互译：主界面左栏为原文、右栏为译文，自动识别正文语言；英文→中文、中文→英文，无需手动选择。划词、粘贴、编辑、截图均使用自动方向。当前不加入其他语言。
4. 「交换」把首次译文放入原文栏，重新自动识别语言，并清除旧译文和当前追问上下文；用户编辑已翻译原文后也清除旧译文与追问，再点击翻译。
5. 新历史附带方向，打开时恢复；旧历史默认为英文→中文。追问用当前界面语言回答。
6. 保存目标、置顶、阅读提示字号与单词本选择一致；保存目标垂直居中对齐。追问仅保留输入提示「输入语法、句意或追问当前选区其他问题」，输入框与按钮等高，保留单独的运行状态行。

## 阅读体验

1. Windows 11；常用阅读器为 Zotero、WPS。
2. 正常阅读英文文献，按需翻译选中区域，不要求整篇翻译。
3. 可选中文字时划词翻译；扫描 PDF 和图片可以截图识别。
4. 截图结果先在选区附近显示简洁弹窗，用户点击按钮才打开主界面。
   小窗与主界面共用公式阅读渲染；原「复制译文」按钮改为「显示原文」，点击后显示当前识别原文并可切回译文，内容可选中复制。保留原有面板外观和操作布局。
   小窗原文或译文中的选词应直接带入收藏编辑窗口，沿用本次原文作为补全语境。收藏窗口不得被置顶小窗遮挡；编辑期间暂时隐藏小窗，保存或取消后恢复，主窗口不自动打开。
   小窗布局保持 v0.3.9：顶部仅标题与关闭按钮，底部仅「打开主界面 / 收藏单词 / 显示原文（或显示译文）」三个按钮；不增加单词本选择框或空白占位区域。
   Alt+X 划词翻译优先显示取词中的小窗，取词和翻译继续异步执行；不等待剪贴板或 WebView2 完成后才显示。公式视图就绪前显示原生文字，取消小窗同时取消取词等待。
5. 悬浮入口可拖动，提供翻译、收藏、手动修改和设置入口。
   悬停展开菜单，鼠标离开浮标和菜单后自动收起；移入菜单时保持展开。单击浮标切换展开/收起，不因同一次点击重新弹出；拖动后不展开菜单。
6. 主界面原文及译文渲染数学公式，保留段落、独立公式和编号；原文可编辑，并可查看本次原始截图核对精确排版。
7. 打开主界面即关闭结果小窗；连续截图/取词时无需先关闭上一次主界面。
8. 划词支持普通浏览器网页中的可复制文字。
9. 轻量弹窗按翻译行数自适应高度；达到原有高度上限后纵向滚动。
10. 英文正文使用 Times New Roman，数学公式正常加载专业数学字体，避免字体回退和过大段间空白。
11. 最小化保留 Windows 任务栏入口及当前内容；点 × 才隐藏到托盘，程序不退出。
12. 左键单击系统托盘图标直接显示并激活主界面，右键保留菜单。切换界面减少重复排版和背景闪烁，保留 v0.3.9 小窗布局；不通过延长动画增加等待。
13. 全局快捷键为 Alt+X 划词、Alt+S 截图、Alt+W 收藏；停用原 Ctrl+Alt+D/T/S/W，保留 Ctrl+Alt+R 显示/隐藏主窗。动作、组合键及提示集中定义，注册/注销、菜单、设置说明、托盘及错误提示共用；占用冲突继续明确提示。本轮不实现自定义快捷键编辑界面或持久化配置。

## 本地历史与临时数据

1. 主界面左侧显示最近 N 次已完成翻译，默认 N=100；设置可调整，N=0 关闭并清空。
2. 历史只存原文/译文；截图、未完成输入、追问不写入历史。当前临时内容在新选区、清空或关闭时释放。
3. 缩小 N 时提示将永久删除的最早记录数量，明确软件内不可恢复，确认后才删除；取消保留现状。
4. 自动淘汰超出上限的最早记录，清理 OCR 与渲染器临时缓存；已收藏单词、Markdown 和配置保持兼容。
5. 左侧品牌与历史栏可收起/展开；收起时保留窄栏展开按钮，释放阅读空间，记住折叠状态，不改变当前原文、译文或历史数据。

## 模型与会话

1. 优先 DeepSeek API，用户在工具内配置 Key。
   模型请求通过可替换的 OpenAI 兼容文本/图片能力接口；原默认地址、模型及 ReadDock 凭据标识不变。默认总超时 100 秒、重试 0。Windows 本地 OCR 路径不变。
   设置提供 DeepSeek / Gitee AI（模力方舟）/ 自定义 OpenAI 兼容预设、HTTPS Base URL、模型名和掩码 Key 输入。Gitee 使用 https://ai.gitee.com/v1，首页地址自动补 /v1，不修改 Codex 配置或登录。
   「获取模型」先将新输入 Key 明确保存到 Windows 凭据管理器，再读取 /models 填充文本/视觉下拉框；服务不支持时可手动填写 ID。列表不代表视觉能力或调用权限。已保存 Key 显示固定黑点占位，真实值不进入输入框、不能复制；留空保留，取消丢弃未保存输入（已经点击获取模型保存的 Key 保留）。服务凭据按来源分别保存，DeepSeek 兼容标识不变。
   测试连接只发固定短文字请求，不重试、不含文献；总超时遵循配置（默认 100 秒），不额外截成 15 秒。Gitee Qwen3-32B 使用 /no_think 短回答提示和 128 token 上限，其余探针沿用 8 token。分别提示未配置、401、402/429、网络、DNS、TLS、代理、超时、输出上限及格式异常；截断结果不得当作完整译文。首次未配置时显示可关闭、可进入设置的非模态引导，文本视图继续可用。
2. 数学文献要考虑斜体拉丁字母 q/p、希腊字母和上下标。用户原图中的 q/p 是数学斜体拉丁字母。
3. 视觉模式发送框选图片；保留只在本地识别图片的 OCR 选项。
4. 默认调用不在聊天客户端创建新会话；每次翻译独立。追问限当前选区。
5. 千问、harness、Codex 插件可作为后续讨论方向，目前未要求优先实现。

## 生词与 Obsidian

1. 选择性收藏单词或词组，收藏前可以手动修改。
2. JSON 定义字段与 Markdown 模板，程序按模板写入用户指定的 Markdown 文件。
3. 支持多个领域单词本，例如 mathematics.md、vla.md；设置默认项。
   每次启动自动发现 Data 根目录中的 .md 文件（不扫描子目录），按文件名加入选择列表，无需逐个登记。保留已有自定义名称、默认/当前目标与外部单词本，按完整路径去重，遵守 40 本上限；不解析、修改或覆盖 Markdown 内容。无旧配置时优先使用发现的单词本，没有发现文件才保留默认新建目标。仅复制单词本不会恢复旧的设置，完整迁移还应保留 Data/settings.json 及自定义模板。
4. 主界面和收藏窗口可选择保存目标；小窗只在标题显示当前单词本，不提供切换控件。没有另选时使用默认/当前项。自动名称「单词本 1 / Notebook 1」跟随 Markdown 文件名，自定义名称保留。主界面右上角不再显示厂商/型号标识。
5. 基础模板保留单词、原形、词性、释义、文献原句、原句译文。开启音标时，收藏编辑和标准 Markdown 均按「原形 → 音标 → 词性」排列。「释义」统一包含当前语境义（在前）及其他常见含义，按需要注明词性，不另列其他词性词义字段。
   设置 → 单词本与模板提供四个左右拨动开关：补充常见变形（默认开，最多 3 个）、写入音标、AI 例句及译文、常见搭配（后三项默认关）。「常见变形」给同词族常见派生词或屈折变化，每行“英文词形 [词性] 中文释义”，不重复所选词、不列无关同义词；优先跨词性，例如 generalizable 可补 generalize、generalization、generalized。AI 输出本地限定最多 3 项，手动超限须修改后才能保存。
   设置存入 JSON，旧 supplement_senses 开关迁移到 include_word_forms 且保留开关值。旧模板中的「语境释义」在本次收藏内存视图改为「释义」；旧 other_meanings 可选字段在内存升级为 word_forms。已有笔记和自定义模板文件不回写；自定义行内音标占位符保持排版，标准独立音标行移动至原形之后。AI 例句与逐字核验的文献原句分开；全部字段可编辑预览后用确定性代码保存。
   收藏窗口底部移除「AI 补全释义」，在「取消」左侧按普通文字按钮提供「补全音标 / AI 例句 / 补充常见搭配」。点击只为当前词条添加字段、请求并更新对应内容；释义、文献原句及其他手动编辑字段保留。设置开关决定每次收藏的默认生成内容，收藏窗口的补充动作不修改默认值、模板文件或后续词条。

6. 默认不放来源、页码、我的笔记、收藏日期。用户以后仍可自定义模板。
7. 按当前目标单词本检查重复。重复确认选「是」以本次词条覆盖旧词条；已有多个同词条卡片时合并替换为本次一张，其他单词和范围外内容保留。选「否」返回编辑，不写文件。替换由本地确定性代码完成，保留写前备份、撤销、文件锁及外部编辑保护；无法安全识别旧词条边界时拒绝覆盖。
8. 软件目录内的单词本、模板及已复制 Logo 以 settings.json 所在目录（通常为 Data）为相对路径基准保存和显示，不依赖进程当前目录；移动整个软件文件夹后保持可用。外部 Obsidian 文件保留绝对路径。旧绝对 Data 路径缺失时，仅当当前 Data 下对应文件存在才恢复；缺失的外部自定义模板不自动替换。

## 外观

主界面名称在最左侧栏顶部，中文界面仅显示「单词猫」，英文仅显示「WordsCat」，不显示第二行重复名称；历史位于其下，标题在当前 DPI 下完整显示。左侧不再显示历史保留说明。按钮、阅读区、历史区和设置页采用柔和圆角，交换等简短操作可使用圆形图标按钮；重要操作及设置导航增加图标，选中导航使用主题色。设置导航中的图标与文字按整体排列，间距固定为 8 逻辑像素，避免短标题前产生过大留白。

设置中的下拉、单行及多行输入、历史条数均有清晰细边框；语言、主题等短选项采用紧凑宽度，文字与下拉箭头处于同一框内。

默认图标使用用户提供的 4.ico，项目内为 assets/wordscat.ico；用于 EXE、悬浮、托盘及窗口。用户可替换 Logo，修改主题色、深浅模式和背景亮度；已有自定义 Logo 优先保留。

主界面粘贴、打开单词本、退出等操作均带图标。鼠标点击结束或关闭设置后不残留强调外框；键盘 Tab/方向键导航时保留清晰的焦点提示。

外观切换立即预览，保存保留、取消恢复；禁用按钮文字也应适配当前主题。自定义浮标 Logo 不被强调色染色。
