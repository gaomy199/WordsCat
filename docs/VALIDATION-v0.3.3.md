## Computer Use

用 computer-use 技能在当前 Windows 桌面打开 --offline-preview，并指定 .test-results/preview-033 隔离配置目录。浮标移至与用户旧版不同的位置，避免入口重叠。

- 鼠标悬停可展开菜单，移入列表保持展开，移出浮标与列表后自动收起。
- 实际连续点击浮标，看到展开、收起、再次展开。菜单关闭后浮标保持可见，下一次点击有效。
- 从菜单点击设置，设置窗口打开且菜单消失；取消设置没有残留菜单。
- 侧栏收起后保留窄栏展开按钮，原文/译文区域变宽；再次点击恢复品牌与历史。重启隔离预览恢复已保存的收起状态。品牌上移且文字完整。

本轮检查中发现并修复：默认自动列宽导致收起按钮越界；系统菜单默认点击处理导致关后重开；非模态菜单关闭后浮标被主窗口遮挡。以上修正均已重测。
