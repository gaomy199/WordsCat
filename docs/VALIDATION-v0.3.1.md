## 实际窗口检查

使用 computer-use 技能在正常 Windows 桌面打开隔离的 `--offline-preview --data-dir <测试目录>`，查看中文浅色主窗口、模型页、外观页，以及英文深色主窗口和设置页。

- 名称在最左上方，中英文分行，底部没有裁切；历史在其下，移除了说明文字。
- 检查圆角按钮、圆形交换按钮、阅读/历史卡片、重要操作图标和设置导航选中态。
- 检查语言/主题短选项、可编辑模型、API 地址等统一边框；实际模型文本保持可编辑，原生下拉键盘和输入行为保留。
- 首次视觉检查发现带图标按钮的文字测量与绘制边距不一致，导致过早省略；已统一边距。还发现默认容器高度撑大自动布局行，导致主界面下拉框落到可见区域之外；已修正默认高度、固定行分配，并新增父行包含检查。
- 深色截图发现 Windows 原生下拉边框和箭头仍为亮色；已用当前主题重绘其外框及箭头。最终 Computer Use 确认主窗口与设置页不再出现亮色内框，并实际展开翻译方向下拉、选择另一方向，标题正常同步。

## 范围

本轮没有读取真实 API Key、请求模型或上传文献。UI 测试使用合成内容及隔离数据。用户尚未实际复测互译和收藏等功能，本轮不新增关于真实翻译、截图识别准确率或跨屏焦点表现的结论。不同 DPI、多屏和不同 Windows 主题仍需在对应环境观察。
