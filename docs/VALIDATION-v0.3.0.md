## Computer Use 检查

使用 computer-use 技能在正常桌面打开独立的 `--offline-preview --data-dir <隔离目录>`：查看中文主界面、外观页语言选项、英文主界面及英文设置页。确认单词猫 / WordsCat 品牌、左侧历史、原文/译文双栏、同字号的保存目标与置顶/阅读提示、等高追问框和按钮。根据实际截图修正保存目标的垂直居中；英文自绘标题中的 & 按字面绘制。

实际使用的 E 盘旧 ReadDock 程序及其 Data 没有被更改；升级入口是正式工作区的 `publish/WordsCat.exe`。在旧安装目录覆盖程序时保留原 Data、笔记、自定义模板及 assets 文件夹；不要只复制一个 exe。

## 验证边界

本轮没有进行中→英或英文→中文的真实联网质量评估。界面及模拟请求检查不能证明模型识别质量；原有复杂数学文献、多屏、混合 DPI、阅读器焦点及同步环境的边界继续保留。当前只提供中英两个翻译方向，未实现其他语言。
