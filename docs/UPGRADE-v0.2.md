# 升级到 ReadDock 0.2

1. 先退出旧版，托盘里也不要继续运行旧进程。
2. 完整解压新版。若覆盖到旧目录，保留原有 `Data` 文件夹和 Markdown 笔记；若放到新目录，则在新设置中重新选择已有笔记路径。
3. 同一 Windows 用户保存的 DeepSeek Key 可以继续使用，不需要发送 Key 到聊天中。
4. 在「设置 → 模型与识别」检查截图模式。数学文献建议使用「DeepSeek 视觉」，默认模型 `deepseek-flash`。此模式会上传本次框选图片。
5. 在「设置 → 单词本与模板」添加 `mathematics.md`、`vla.md` 等文件，并勾选一个默认项。主窗口和收藏窗口可切换保存目标。
6. 如旧的自定义模板仍有不需要的字段，点「使用精简模板」并保存设置；原模板和旧卡片会保留。
7. 在「设置 → 外观」选择自己的 Logo、强调色、深浅模式及背景亮度。

主窗口右上角 `v0.2` 可用于确认当前版本。截图完成后只显示轻量弹窗，点击「打开主界面」才显示完整窗口。
