# 单词猫 WordsCat 0.4.1 · Windows 11

中英互译与 Obsidian 生词收藏。

## 下载即用

前往 [GitHub Releases](https://github.com/gaomy199/WordsCat/releases)，选择对应版本的 `WordsCat-VERSION-win-x64.zip`，完整解压后双击 `WordsCat/WordsCat.exe`。自包含便携包不需要下载源码仓库或自行构建，已包含 .NET 10 Windows Desktop Runtime。GitHub 自动附带的 Source code 压缩包是源码，请选择带有 win-x64 名称的程序压缩包。

本地打包后的直接可用压缩包位于项目根目录下的 `dist/`，校验文件为 `dist/SHA256SUMS.txt`。默认 `publish/` 是依赖本机 .NET 10 运行时的开发构建目录；生成本地压缩包不会自动上传 GitHub。

当前工作区 0.4.1 编译至 `publish/WordsCat.exe`，本轮不生成新压缩包、不提交、不推送；远端可用版本以所选 Release 为准。

从 0.4.1 起，新压缩包采用「外层 WordsCat.exe 启动入口 + app/ 程序子目录」。程序、运行时、公式资源、说明和许可文件放在 app/，使用时双击外层 WordsCat.exe，保留完整 app/。Data/ 放在外层启动入口旁边，首次运行会自动创建；开发用 publish/ 仍沿用原来的平铺结构。

不保留旧翻译历史时，先退出旧程序，在新解压目录的外层新建一个干净的 Data/，复制最近使用的 settings.json、vocabulary.template.json（或设置中选用的模板）和 Markdown 单词本即可。若配置引用其他自定义模板或 Appearance/ 中的 Logo，也要复制对应文件；外部路径的文件仍须保留。无需复制 reading-history.dat、缓存或旧备份。如果目标 Data/ 已经有历史，仅覆盖这几个文件不会清除目标历史，因此应使用新建的 Data/。本次整理不会删除或搬动你原来的文件。

目前提供 Windows 11 x64 便携版本；首次使用在设置中填写 API Key 和单词本。升级先退出旧版，保留原有 Data 文件夹和 Markdown 笔记。

## 从 0.1 升级

1. 在旧版托盘或主窗口中点「退出」，避免两个版本同时运行。
2. 将新版 ZIP 完整解压。可以放到新目录，也可以将程序文件覆盖到旧目录；**保留你原有的 Data 文件夹和 Markdown 笔记**。
3. 若覆盖原目录，旧的单个 Markdown 路径会自动成为一个单词本。未修改过的旧默认模板会备份为 `.v0.1.backup` 后换成精简版；你自行改过的模板会保留。
4. 若放到新目录，重新在设置中添加已有 Markdown 文件即可。Windows 同一用户保存的 DeepSeek Key 可继续使用。
5. 如果仍看到旧字段，在「设置 → 单词本与模板」点「使用精简模板」，保存设置。

当前源码要求 .NET 10 SDK；默认开发构建的运行环境为 .NET 10 Windows Desktop Runtime（x64），自包含 Release 构建会随包提供该运行时。公式阅读使用 Microsoft Edge WebView2 Runtime，公式字体和 KaTeX 已随包提供，阅读渲染无需联网；缺少 WebView2 时可先使用文本页。不要只移动 exe，也不要在 ZIP 内直接运行；保留 assets/math 文件夹。

## 界面语言与中英互译

点击左侧名称旁的侧栏图标可收起品牌和历史记录，点击窄栏里的图标重新展开；程序会记住状态。收起只调整界面，不清空当前翻译或历史。

鼠标悬停在悬浮图标上约 350ms 展开菜单；离开浮标和列表后短暂延迟自动收起，鼠标移入列表时不会收起。也可点击浮标展开，再次点击收起；拖动浮标仍可调整位置。

在「设置 → 外观 → 界面语言」选择简体中文或 English，选择后主窗口和设置页立即预览；保存后保留，取消恢复原语言。该选项独立于翻译方向，也不会改动原文、术语表、笔记或自定义模板。

主界面最左侧顶部只显示当前界面语言的名称，下方为历史记录；主操作区左栏为原文，右栏为译文。输入原文后自动识别语言：英文翻译成中文，中文翻译成英文。输入或粘贴后点「翻译当前原文」；划词和截图同样自动判断，不再需要选择方向。数学公式中的变量与 LaTeX 命令不参与文本语言判断；中英混排依据正文主要语言。点「交换」把首次译文放入原文栏，重新自动识别后再点翻译。编辑已经翻译过的原文会清除旧译文和追问上下文。历史记录恢复时也会恢复当时的翻译方向；旧版记录视为英文 → 中文。追问使用当前界面语言回答。

默认图标是随程序嵌入的书本图标（用户提供的 4.ico），不依赖原电脑上的图片路径。已有自定义 Logo 仍优先使用；在设置中点「恢复默认 Logo」可使用新版默认图标。

从 ReadDock 升级时保留同目录的 Data 文件夹和现有笔记，启动 WordsCat.exe。凭据继续使用原 Windows 凭据目标，旧 Key 无需重填；项目源码目录及内部兼容标识仍保留 ReadDock。

## 第一次配置

打开 `WordsCat.exe`，进入「设置」。

首次启动且未配置 Key 时，会出现可关闭的简短引导，可点「打开设置」或「稍后设置」；不会阻塞文本视图。

**模型与识别 → 模型服务**：预设可选 DeepSeek、「Gitee AI · 模力方舟」或「自定义 OpenAI 兼容」。DeepSeek 默认地址仍为 `https://api.deepseek.com`，文本与视觉模型均为 `deepseek-flash`；Gitee 预设使用 `https://ai.gitee.com/v1`，填写其首页地址时也会自动补上 `/v1`。自定义服务填写其 HTTPS Base URL。

API Key 框用固定黑点表示当前服务已有密钥；黑点只是占位，真实已保存 Key 不进入输入框、无法复制。输入新 Key 时掩码显示，留空保留旧值，取消丢弃尚未保存的输入。不同来源的 Key 分别保存在 Windows 凭据管理器，不写入配置 JSON；DeepSeek 的旧 ReadDock 凭据标识保留。无需将 Key 发到聊天中。

填入 Key 后点「获取模型」：程序会立即保存新 Key，再读取此服务的 `/models` 列表，不发送文献内容。此时密钥已保存，之后取消设置不会撤销该次密钥保存。文本模型和视觉模型都可从返回列表选择，最后保存设置。不支持模型列表的服务仍可手动填写模型 ID。列表不保证账号有调用权限或模型支持图片；截图请选支持图片的视觉型号，或使用 Windows 本地 OCR。视觉模型留空时使用文本模型。此配置仅作用于单词猫，不改 Codex 的配置或官方账号登录。接口参考：[Gitee 官方兼容接口说明](https://ai.gitee.com/docs/integrations/Development-Tools/catpaw)。

截图有两种模式：

| 模式 | 处理方式 | 适用场景 |
| --- | --- | --- |
| DeepSeek 视觉（默认） | 将本次框选图片发给 API，一次返回识别原文和中文译文 | 数学斜体、上下标、希腊字母、扫描文献 |
| Windows 本地 OCR | 本地放大、增强后识别，只将识别文字发给 API 翻译 | 普通英文、希望图片留在本地的情况 |

**视觉模式会上传选区图片，产生相应 API 用量**。它使用支持图片的视觉模型，不要求文本翻译模型也具备图片能力。可在设置中编辑视觉模型名称；填写不支持图片的模型时，服务可能拒绝请求。

没有 Key 时只做本地识别并显示原文；不会把英文原文当作已经完成的中文翻译。中文 Windows OCR 对数学字体仍可能误读，这也是视觉模式加入的原因。

保存后重新打开设置，点「测试连接」：使用已保存凭据，只发送一次固定短文字请求，不包含文献内容或图片、不重试。总超时遵循配置，默认 100 秒，不再额外截成 15 秒；Gitee Qwen3-32B 使用 `/no_think` 短回答提示和 128 token 上限，其余探针保留 8 token。结果分别提示未配置 Key、401 Key 无效、402/429 额度或频率限制、DNS、HTTPS、代理、其他网络故障、实际超时、输出达上限或返回格式异常。新 Key 未保存时会提示先保存；测试成功只说明文本服务响应，不验证视觉能力。模型服务器的日志、缓存及数据保留按服务商政策处理。

## 设置不同领域的单词本

每次启动会自动发现程序 `Data` 根目录里的 `.md` 文件，按文件名加入单词本列表，无需逐个登记。把已有单词本复制到新版的 `Data` 文件夹，重启程序即可选择；不扫描子目录、不修改笔记内容。已有名称、默认项和外部单词本路径保留，已登记路径不重复添加，总数最多 40 本。如果只移除配置项、文件仍留在 Data 根目录，下次启动会再次发现。若要同时保留旧默认项、模型设置和自定义模板，请迁移整个 Data 文件夹（包括 settings.json），而不只是 Markdown 文件。

在「设置 → 单词本与模板」中：

1. 点击「添加单词本」。
2. 填写名称，例如 `mathematics` 或 `vla`。
3. 点击该行的「选择文件」，选择 Obsidian 仓库内的 `.md` 文件，也可以输入一个新文件名。
4. 勾选一个「默认」项，保存设置。

主窗口上方和收藏编辑窗口有「保存到」选择；小窗只在标题显示当前单词本，保持 v0.3.9 的标题与关闭按钮、底部三个操作按钮布局。程序每次启动使用默认单词本，本次切换不改变默认设置。未勾选默认项时使用列表第一项。「单词本 1」等自动名称按所选文件名更新，例如 `locomanipulation-words`；自定义名称保留。

同一个词可以分别加入不同领域的单词本；重复提醒只检查当前选择的文件。「移除所选项」只移除路径配置，不删除 Markdown 文件。最多添加 40 个单词本，名称和文件路径不能重复。

## 阅读与轻量弹窗

| 快捷键 | 功能 |
| --- | --- |
| `Alt+X` | 翻译阅读器中已选中的文字，先显示小窗 |
| `Alt+S` | 截图识别与翻译 |
| `Alt+W` | 收藏单词 |
| `Ctrl+Alt+R` | 显示或隐藏主窗口 |
| `Ctrl+Q` | 在主窗口退出程序 |

表中前四项为可自定义的全局快捷键，列出的是默认值。在「设置 → 阅读偏好」点击对应方框，按下包含 Ctrl 或 Alt 的新组合键（可加 Shift），保存后立即生效并在重启后保留；取消保留原配置。「恢复默认快捷键」重置本次设置草稿。重复组合或被系统、其他软件占用的组合会提示并阻止保存。设置打开期间暂时释放本应用的全局快捷键，以便录入。

截图后默认在选区下方显示一个简洁弹窗，不弹出主窗口。下方空间不足时，弹窗移到上方并限制在屏幕范围内。弹窗显示渲染后的译文、状态和「打开主界面」「收藏单词」「显示原文」按钮；点击「显示原文」查看本次识别原文及公式，再点击「显示译文」返回。可在阅读区选中文本后复制。可以拖动标题移动位置，Esc 或右上角 × 关闭。

手动拖动后，本次小窗在关闭前保持拖动位置，切换原文/译文或内容更新不会跳回初始位置。关闭后重新划词或截图唤起新小窗，仍按原有规则在选区附近定位。

划词时先显示「正在获取」小窗，取词和翻译继续在后台执行；公式视图初始化期间先显示原生文字。弹窗随译文实际行数增高，短译文不会留大块空白；达到原有最大高度后显示纵向滚动条。主窗口最小化后保留任务栏入口及当前内容，点 × 隐藏到托盘；左键单击托盘图标即可打开主界面，右键仍为菜单。选择“退出”才完全关闭程序。界面切换通过减少重复排版与双缓冲减少闪烁，不增加动画等待。

点击「打开主界面」后，小窗随即退出，显示识别原文、修改、继续追问和更多设置。连续截图或取词无需先关闭上一次主界面。识别不确定的字符会在状态中提示；可在主窗口校正原文，再翻译。

主界面左右两侧的「阅读」页会将 LaTeX 渲染为分式、上下标及独立公式，并保留识别文本的段落结构。「编辑原文」可校正识别结果，「文本」可查看译文源码；阅读页也可选词收藏。「原始截图」保留本次截图以核对原有字体和精确排版。译文按窗口宽度重排，不是逐像素复刻原图；清空或关闭本次内容后释放截图。

左右阅读区的中文字符及中文标点为 16px，比原版小 2px；英文保留 18px，公式字号保持原样，中英混排也分别应用。阅读页签周围间距收紧，卡片与底部操作/追问区之间保留明确空隙。下拉框和追问框文字垂直居中，追问框为单行，Enter 继续发送。

轻量弹窗与主界面共用本地 KaTeX 渲染，原文和译文均支持分式、上下标与独立公式；小面板使用 16px 阅读字号，公式按相同比例显示。新选区会清除上一选区的原文与切换状态；关闭后释放当前内容。Obsidian 收藏继续保留原始数学表达式。缺少 WebView2 时回退为可复制的文本视图。

在小窗原文或译文中选词后点「收藏单词」，收藏窗口会带入所选文字，并沿用本次识别原文作为语境进行已有的自动补全。编辑期间暂时隐藏小窗，关闭收藏窗口后恢复，主窗口保持隐藏。自动补全需要已保存的 API Key，未配置时仍可手动填写。

英文正文使用 Times New Roman；公式使用随程序附带的专用数学字体，保持分式、上下标和符号的标准排版。升级时请复制完整 assets/math 目录。

网页中先选中文字，再按 `Alt+X`，或使用浮标的「划词翻译」。不允许复制的网页及扫描图片可改用截图。

截图框选时松开鼠标完成，Esc / 右键取消。建议放大文献并只选一栏正文。普通划词通过复制操作读取选区，会尽量恢复原剪贴板；失败时可以手动复制、粘贴。阅读器以管理员权限运行时可能无法划词。

## 收藏生词

在主窗口原文中选中单词或词组，点击「收藏所选词」，也可选中轻量弹窗原文或译文中的单词再点「收藏单词」。收藏前可以修改所有字段，并选择目标单词本。

基础模板包含以下六个字段；默认另外开启「常见变形」（最多 3 个），可在设置中关闭。开启音标后按「原形 → 音标 → 词性」显示并保存：

- 单词 / 词组
- 原形
- 词性
- 释义（当前语境义在前，再补充其他常见义）
- 文献原句
- 原句译文

来源、页码、我的笔记、收藏日期不再出现在默认模板和示例中。现有笔记中已保存的旧卡片不会被自动修改。

已配置 Key 且词条带有初始选词时，打开收藏窗口自动补全释义及设置中默认开启的内容。底部不再显示「AI 补全释义」，而是在「取消」左侧提供「补全音标」「AI 例句」「补充常见搭配」三个按钮：只为当前词条补充对应字段，不改已有释义、文献原句等其他编辑内容。单次按钮不改变设置默认值；新字段可编辑，并加入本次 Markdown 预览和保存。原句必须来自当前识别或粘贴的原文，无法核验的模型原句会留空。词条与释义必填，保存前请核对数学符号和专业含义。

三个补充按钮点击一次开启并保持浅色高亮，再次点击恢复未选中颜色，移除对应字段以及本次 Markdown 预览和保存中的补充内容；AI 例句及译文一起切换。默认设置或模板已有对应字段时，按钮初始即为高亮。撤销补充不调用模型，不改其他编辑内容；再次开启会重新补充。

重复词会先询问是否覆盖旧词条：选「是」以本次词条替换当前单词本中的旧词条，原来已有多个同词卡片时合并为本次一张；选「否」返回编辑，不保存。其他单词保留，无法安全识别旧词条边界时拒绝覆盖。每次保存前保留备份，最近 20 份在 `Data/Backups`。撤销同样支持覆盖操作，作用于本次运行内最近一次收藏；笔记之后若有外部编辑，拒绝自动回退以保留你的改动。

收藏界面仍保留空白字段及输入框；Markdown 预览和实际写入只输出有内容的字段，空值或仅有空格、换行的字段不显示标题和空行，包括文献原句、原句译文、常见变形及补充内容。后续给同一单词补上内容，再选择覆盖，就会用当前完整词条替换旧词条并写入新增内容；不会自动改动已有笔记。

笔记使用 UTF-8 `.md`，新词追加写入，确认的重复词按词条范围覆盖，其他内容保留。每个文件上限 20 MB。同步软件或 Obsidian 同时编辑造成占用时请稍后重试；未落盘的编辑和云同步冲突由编辑器及同步软件处理。

## 自定义外观

「设置 → 外观」提供：

- 浅色、深色、跟随系统三种模式。
- 主题强调色：输入 `#RRGGBB` 或点击「选择颜色」。
- 背景亮度：滑块向左较暗、向右较亮。
- 自定义 Logo：支持 PNG、JPG、ICO；应用于悬浮图标、托盘图标和窗口图标。该设置不修改 exe 文件在资源管理器中的图标资源。

模式、强调色、亮度与 Logo 调整会立即在设置、主窗口和浮标预览，保存后保留，取消则恢复。自定义浮标 Logo 使用中性背景，不受强调色染色。Logo 保存时复制到 `Data/Appearance/logo.png`，不会锁住原图片。可点「恢复默认 Logo」；「预览外观」显示示例弹窗，不调用 API。

## JSON 模板与数据

`Data/vocabulary.template.json` 是首次启动生成的可编辑默认模板，可在设置中选择另一个 JSON。`fields` 定义字段的 key、中文标签、说明、必填和多行属性；`entry_template` 定义 Markdown 排版，用 `{{word}}` 等占位符插入字段。

必须保留必填的 `word`，支持 1—30 个字段。普通文本按 Markdown 转义，内联 LaTeX 保留。程序提供的 `id`、`date`、`captured_at` 仍可在自定义模板里使用，但精简模板不输出日期。

配置文件为 `Data/settings.json`。应用内单词本、模板和 Logo 按配置目录保存相对路径，外部路径保持绝对。Key 存在当前 Windows 用户的凭据管理器中：DeepSeek 保留 `ReadDock.DeepSeek.ApiKey.v1`，其他服务按 HTTPS 来源分别保存；输入框留空保存会保留对应凭据。

主界面左侧“最近翻译”默认保留最近 100 次已完成翻译的原文和译文。选中记录后点“打开记录”或双击即可查看；截图和后续追问不写入历史。历史在 Data/reading-history.dat 中由当前 Windows 账户加密保存，不创建聊天客户端会话。

在“设置 → 阅读偏好”调整保留条数（0—1000）。设为 0 会关闭并清空历史。缩小上限时，程序显示将删除的最早记录数量并警告无法恢复，确认后才执行；例如现有 100 条改成 10 条，将删除最早的 90 条。超限时也会自动淘汰最早记录。删除只影响本地翻译历史，不影响已收藏单词和 Markdown；软件不提供历史回收站或备份。

新选区、粘贴新原文、清空或点 × 会释放当前截图、输入和追问；最小化保留当前内容。OCR 临时图片处理后删除，渲染缓存退出后随浏览器释放自动清理；异常退出遗留在下次启动补清理。配置、笔记和单词备份保留。历史文件只能由原 Windows 账户解密。

视觉请求完成后，后续追问只携带当前选区的文字，不重复发送图片。取消请求会停止本地等待，已经发送的请求仍可能产生用量，不自动重试。

## 收藏内容开关与移动文件夹（0.3.9）

「设置 → 单词本与模板」提供四个左右拨动开关：常见变形（默认开启，最多 3 个）、音标、AI 例句及译文、常见搭配（后三项默认关闭）。释义统一包含当前语境义及其他常见义，不另列中文含义补充栏。常见变形每行填写“英文词形 [词性] 中文释义”；如 generalizable 可给出 generalize [v.] 概括、推广，generalization [n.] 概括、推广，generalized [adj.] 一般的、笼统的。AI 输出最多保留 3 项，手动超过 3 项需要修改后才能保存。

音标在原形之后、词性之前；AI 例句单列，文献原句继续逐字核验。保存前可编辑并查看 Markdown 预览。旧开关值自动继承到常见变形开关；旧模板的「语境释义」在收藏窗口内显示为「释义」，不改写模板文件或已有笔记。自定义行内排版保留，标准独立音标行按新顺序显示。

软件目录内的单词本、模板及 Logo 路径按 settings.json 所在目录（通常为 Data）保存为相对路径。剪切或移动时请带上整个软件文件夹与 Data；外部 Obsidian 单词本保留绝对路径。旧版绝对 Data 路径失效后，若当前 Data 中对应文件存在会自动恢复；其他缺失的自定义模板需重新选择。
